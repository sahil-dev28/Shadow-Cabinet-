# Shadow Cabinet — CXO Board Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A CEO poses a business question and four executive personas answer independently, then challenge each other, grounded in uploaded P&L data, in a thread that survives a restart.

**Architecture:** Four Mastra agents built from one persona factory share a board thread. A two-pass workflow fans the question out to all four concurrently (pass one), shows each the others' replies and collects a structured disagreement verdict (pass two), and renders both rounds as markdown streamed to assistant-ui. Numbers never enter a system prompt — agents pull them through four narrow tools backed by MongoDB.

**Tech Stack:** Mastra 1.57 (`@mastra/core`, `@mastra/ai-sdk`, `@mastra/memory`, `@mastra/mongodb`), Anthropic `claude-sonnet-4-5`, Zod 4, Next.js 16 + assistant-ui + `ai@7`, Vitest, pnpm workspace.

**Spec:** `docs/superpowers/specs/2026-08-11-shadow-cabinet-design.md`

## Global Constraints

- Node `>=22.13.0`. ESM only (`"type": "module"`); CommonJS breaks Mastra.
- Local imports carry the `.ts` extension (`./agents/cfo-agent.ts`). `allowImportingTsExtensions: true` is already set in the root `tsconfig.json`.
- Model string is always `anthropic/claude-sonnet-4-5`. Never `anthropic:` and never a provider object. Requires `ANTHROPIC_API_KEY` in the repo-root `.env`.
- Zod 4 (`zod@^4.4.3`) for every schema.
- Tools MUST be created with `createTool()` from `@mastra/core/tools`. Plain object tool definitions silently fail to execute.
- All server source lives under `shadow-cabinet-server/src/mastra/`. The root `tsconfig.json` `include` is `["shadow-cabinet-server/src/**/*"]`.
- Custom API route paths must NOT start with `/api` — that prefix is reserved for built-in Mastra routes.
- No auth, no polish, no real financial integrations (assignment says so explicitly).
- Run the server from the repo root with `pnpm dev`; the web app from `shadow-cabinet-web` with `pnpm dev`.
- Type-check with `pnpm exec tsc --noEmit` from the repo root. Tests with `pnpm test`.

```ts
export interface Segment {
  name: string;
  revenue: number;
  grossMarginPct: number;
}

export interface Quarter {
  period: string;
  revenue: number;
  cogs: number;
  grossProfit: number;
  grossMarginPct: number;
  salesMarketing: number;
  rnd: number;
  ga: number;
  operatingIncome: number;
  operatingMarginPct: number;
  cash: number;
  headcount: number;
  newCustomers: number;
  churnPct: number;
  cac: number;
  ltv: number;
  segments: Segment[];
}

export interface CompanyData {
  company: string;
  currency: string;
  unit: string;
  quarters: Quarter[];
}

export const METRIC_NAMES = [
  "revenue",
  "cogs",
  "grossProfit",
  "grossMarginPct",
  "salesMarketing",
  "rnd",
  "ga",
  "operatingIncome",
  "operatingMarginPct",
  "cash",
  "headcount",
  "newCustomers",
  "churnPct",
  "cac",
  "ltv",
] as const;

export type MetricName = (typeof METRIC_NAMES)[number];

export function listPeriods(data: CompanyData): string[] {
  return data.quarters.map((quarter) => quarter.period);
}

function requireQuarter(data: CompanyData, period: string): Quarter {
  const quarter = data.quarters.find((entry) => entry.period === period);
  if (!quarter) {
    throw new Error(
      `Unknown period "${period}". Valid periods: ${listPeriods(data).join(", ")}.`,
    );
  }
  return quarter;
}

function requireMetric(metric: string): MetricName {
  if (!METRIC_NAMES.includes(metric as MetricName)) {
    throw new Error(
      `Unknown metric "${metric}". Valid metrics: ${METRIC_NAMES.join(", ")}.`,
    );
  }
  return metric as MetricName;
}

export function getMetric(
  data: CompanyData,
  metric: MetricName,
  period: string,
): { metric: MetricName; period: string; value: number } {
  const name = requireMetric(metric);
  const quarter = requireQuarter(data, period);

  return { metric: name, period, value: quarter[name] };
}

export function compareMetric(
  data: CompanyData,
  metric: MetricName,
  fromPeriod: string,
  toPeriod: string,
): {
  metric: MetricName;
  from: { period: string; value: number };
  to: { period: string; value: number };
  delta: number;
  deltaPct: number;
} {
  const from = getMetric(data, metric, fromPeriod);
  const to = getMetric(data, metric, toPeriod);

  const delta = to.value - from.value;
  // Guard against a zero baseline so the tool never returns Infinity or NaN.
  const deltaPct = from.value === 0 ? 0 : (delta / from.value) * 100;

  return {
    metric: from.metric,
    from: { period: from.period, value: from.value },
    to: { period: to.period, value: to.value },
    delta,
    deltaPct,
  };
}

export function getSegmentMix(
  data: CompanyData,
  period: string,
): {
  period: string;
  totalRevenue: number;
  segments: Array<{
    name: string;
    revenue: number;
    revenueSharePct: number;
    grossMarginPct: number;
  }>;
} {
  const quarter = requireQuarter(data, period);
  const totalRevenue = quarter.revenue;

  return {
    period,
    totalRevenue,
    segments: quarter.segments.map((segment) => ({
      name: segment.name,
      revenue: segment.revenue,
      revenueSharePct:
        totalRevenue === 0 ? 0 : (segment.revenue / totalRevenue) * 100,
      grossMarginPct: segment.grossMarginPct,
    })),
  };
}
```

```ts
import { createTool } from "@mastra/core/tools";
import { z } from "zod";

import {
  METRIC_NAMES,
  compareMetric,
  getMetric,
  getSegmentMix,
  listPeriods,
} from "../data/company-data.ts";
import { getCompanyData } from "../data/company-data-provider.ts";

const metricSchema = z
  .enum(METRIC_NAMES)
  .describe("The metric to look up. Must be one of the listed names.");

const periodSchema = z
  .string()
  .describe('A fiscal period such as "2025-Q3". Call listPeriods first if unsure.');

/** Percentage metrics are already percentages; everything else is a raw figure. */
function unitFor(metric: string): string {
  if (metric.endsWith("Pct")) return "percent";
  if (metric === "headcount" || metric === "newCustomers") return "count";
  return "USD thousands";
}

/** Turns a thrown Error into data the model can read and correct itself with. */
function asError(error: unknown): { ok: false; error: string } {
  return {
    ok: false,
    error: error instanceof Error ? error.message : String(error),
  };
}

export const listPeriodsTool = createTool({
  id: "list-periods",
  description:
    "List every fiscal period for which company figures exist. Call this before any other data tool if you are unsure which periods are available.",
  inputSchema: z.object({}),
  outputSchema: z.object({
    ok: z.boolean(),
    periods: z.array(z.string()).optional(),
    error: z.string().optional(),
  }),
  execute: async () => {
    try {
      const data = await getCompanyData();
      return { ok: true as const, periods: listPeriods(data) };
    } catch (error) {
      return asError(error);
    }
  },
});

export const getMetricTool = createTool({
  id: "get-metric",
  description:
    "Get one company metric for one period. Use this whenever you need to cite a figure. Never estimate a number you have not looked up.",
  inputSchema: z.object({ metric: metricSchema, period: periodSchema }),
  outputSchema: z.object({
    ok: z.boolean(),
    metric: z.string().optional(),
    period: z.string().optional(),
    value: z.number().optional(),
    unit: z.string().optional(),
    error: z.string().optional(),
  }),
  execute: async ({ metric, period }) => {
    try {
      const data = await getCompanyData();
      const result = getMetric(data, metric, period);
      return { ok: true as const, ...result, unit: unitFor(result.metric) };
    } catch (error) {
      return asError(error);
    }
  },
});

export const compareMetricTool = createTool({
  id: "compare-metric",
  description:
    "Compare one metric across two periods and get the absolute and percentage change. Use this for any quarter-over-quarter claim instead of doing the arithmetic yourself.",
  inputSchema: z.object({
    metric: metricSchema,
    fromPeriod: periodSchema,
    toPeriod: periodSchema,
  }),
  outputSchema: z.object({
    ok: z.boolean(),
    metric: z.string().optional(),
    from: z.object({ period: z.string(), value: z.number() }).optional(),
    to: z.object({ period: z.string(), value: z.number() }).optional(),
    delta: z.number().optional(),
    deltaPct: z.number().optional(),
    unit: z.string().optional(),
    error: z.string().optional(),
  }),
  execute: async ({ metric, fromPeriod, toPeriod }) => {
    try {
      const data = await getCompanyData();
      const result = compareMetric(data, metric, fromPeriod, toPeriod);
      return { ok: true as const, ...result, unit: unitFor(result.metric) };
    } catch (error) {
      return asError(error);
    }
  },
});

      const data = await getCompanyData();
```

```ts
import { Agent } from "@mastra/core/agent";

import { companyDataTools } from "../tools/company-data-tools.ts";

export type PersonaId = "cfo" | "cmo" | "coo" | "cso";

export const PERSONA_IDS: readonly PersonaId[] = ["cfo", "cmo", "coo", "cso"];

export interface PersonaConfig {
  id: PersonaId;
  /** Display title, e.g. "Chief Financial Officer". */
  title: string;
  /** What this executive optimises for. One paragraph. */
  lens: string;
  /** How this executive argues, including who they clash with. One paragraph. */
  character: string;
}

/**
 * Every persona shares this contract. Only `lens` and `character` differ,
 * which is what keeps four voices distinct without letting them drift into
 * four different answer formats.
 */
function buildInstructions(config: PersonaConfig): string {
  return `
You are the ${config.title} on a virtual executive board advising the CEO.

## Your lens
${config.lens.trim()}

## Grounding rules
You have tools that return the company's real figures. Use them.
- Never invent, estimate, or recall a number. If you did not fetch it with a
  tool in this conversation, do not state it.
- Call listPeriods first if you are unsure which periods exist.
- Use compareMetric for any quarter-over-quarter claim. Do not do the
  arithmetic yourself.
- Use getSegmentMix before blaming or clearing "mix shift".
- If the data needed to answer does not exist, say exactly which figure is
  missing instead of guessing.

## How you respond
- Lead with your position, then the reasoning. Do not bury the verdict.
- Cite the figures you fetched, with their periods.
- Name the trade-off explicitly. Every recommendation costs something.
- Keep it under 200 words. You are one voice in a board meeting, not a memo.

## Your character
${config.character.trim()}
`.trim();
}

export function createPersonaAgent(config: PersonaConfig): Agent {
  return new Agent({
    id: `${config.id}-agent`,
    name: config.id.toUpperCase(),
```

Create `shadow-cabinet-server/src/mastra/workflows/transcript.ts`:

```ts
import { PERSONAS, PERSONA_IDS, type PersonaId } from "../agents/index.ts";

export interface OpeningEntry {
  personaId: PersonaId;
  text: string;
}

export interface RebuttalEntry {
  personaId: PersonaId;
  disagrees: boolean;
  with: PersonaId[];
  statement: string;
}

/** Pass one runs concurrently, so impose a stable order before rendering. */
export function sortByBoardOrder<T extends { personaId: PersonaId }>(
  entries: T[],
): T[] {
  return [...entries].sort(
    (a, b) =>
      PERSONA_IDS.indexOf(a.personaId) - PERSONA_IDS.indexOf(b.personaId),
  );
}

function heading(personaId: PersonaId): string {
  return `### ${personaId.toUpperCase()} — ${PERSONAS[personaId].title}`;
}

export function renderOpeningRound(entries: OpeningEntry[]): string {
  const sections = sortByBoardOrder(entries).map(
    (entry) => `${heading(entry.personaId)}\n\n${entry.text.trim()}`,
  );

  return `## Opening statements\n\n${sections.join("\n\n")}\n`;
}

/**
 * An agent flagged as disagreeing but with nothing to say is treated as
 * agreement. Otherwise an empty section renders under the disagreement
 * heading and reads as a bug.
 */
export function filterDisagreements(entries: RebuttalEntry[]): RebuttalEntry[] {
  return sortByBoardOrder(entries).filter(
    (entry) => entry.disagrees && entry.statement.trim().length > 0,
  );
}

export function renderRebuttalRound(entries: RebuttalEntry[]): string {
  const disagreements = filterDisagreements(entries);

  if (disagreements.length === 0) {
    return "## Where the board disagrees\n\nThe board did not disagree on this question.\n";
  }

  const sections = disagreements.map((entry) => {
    const targets =
      entry.with.length > 0
        ? entry.with.map((id) => id.toUpperCase()).join(", ")
        : "the board";

    return `**${entry.personaId.toUpperCase()} → ${targets}**\n\n${entry.statement.trim()}`;
  });

  return `## Where the board disagrees\n\n${sections.join("\n\n")}\n`;
}

/** The other executives' openings, as one persona will see them in pass two. */
export function formatOpeningsForRebuttal(
  entries: OpeningEntry[],
  excluding: PersonaId,
): string {
  return sortByBoardOrder(entries)
    .filter((entry) => entry.personaId !== excluding)
    .map(
      (entry) =>
        `${entry.personaId.toUpperCase()} (${PERSONAS[entry.personaId].title}):\n${entry.text.trim()}`,
    )
    .join("\n\n");
}
```

```ts
import { createStep, createWorkflow } from "@mastra/core/workflows";
import { z } from "zod";

import { PERSONA_IDS, type PersonaId } from "../agents/index.ts";
import {
  type OpeningEntry,
  formatOpeningsForRebuttal,
  renderOpeningRound,
  renderRebuttalRound,
} from "./transcript.ts";

const personaIdSchema = z.enum(PERSONA_IDS as unknown as [PersonaId, ...PersonaId[]]);

const boardInputSchema = z.object({
  question: z.string().min(1),
  threadId: z.string().min(1),
});

const openingEntrySchema = z.object({
  personaId: personaIdSchema,
  text: z.string(),
  question: z.string(),
  threadId: z.string(),
});

const rebuttalEntrySchema = z.object({
  personaId: personaIdSchema,
  disagrees: z.boolean(),
  with: z.array(personaIdSchema),
  statement: z.string(),
});

/** The shape pass two asks each persona to return. */
const verdictSchema = z.object({
  disagrees: z
    .boolean()
    .describe("True only if you have a substantive objection to another executive's position."),
  with: z
    .array(personaIdSchema)
    .describe("The persona ids you are objecting to. Empty if disagrees is false."),
  statement: z
    .string()
    .describe("Your objection, under 120 words. Empty string if disagrees is false."),
});

/** Pass one: one persona answers the CEO without seeing its peers. */
const openingStep = createStep({
  id: "opening",
  inputSchema: z.object({
    personaId: personaIdSchema,
    question: z.string(),
    threadId: z.string(),
  }),
  outputSchema: openingEntrySchema,
  execute: async ({ inputData, mastra }) => {
    const { personaId, question, threadId } = inputData;
    const agent = mastra.getAgentById(`${personaId}-agent`);

    const response = await agent.generate(question, {
      memory: { resource: "ceo", thread: threadId },
    });

    return { personaId, text: response.text, question, threadId };
  },
});

const renderOpeningsStep = createStep({
  id: "render-openings",
  inputSchema: z.array(openingEntrySchema),
  outputSchema: z.object({
    question: z.string(),
    threadId: z.string(),
    openings: z.array(z.object({ personaId: personaIdSchema, text: z.string() })),
  }),
  execute: async ({ inputData, writer }) => {
    const openings: OpeningEntry[] = inputData.map((entry) => ({
      personaId: entry.personaId,
      text: entry.text,
    }));

    // Stream the whole round at once so the sections cannot interleave.
    await writer?.write(renderOpeningRound(openings));

    return {
      question: inputData[0].question,
      threadId: inputData[0].threadId,
      openings,
    };
  },
});

/** Pass two: this persona reads the others and says whether it objects. */
const rebuttalStep = createStep({
  id: "rebuttal",
  inputSchema: z.object({
    personaId: personaIdSchema,
    question: z.string(),
    threadId: z.string(),
    openings: z.array(z.object({ personaId: personaIdSchema, text: z.string() })),
  }),
  outputSchema: rebuttalEntrySchema,
  execute: async ({ inputData, mastra }) => {
    const { personaId, question, threadId, openings } = inputData;
    const agent = mastra.getAgentById(`${personaId}-agent`);

    const others = formatOpeningsForRebuttal(openings, personaId);

    const response = await agent.generate(
      `The CEO asked: "${question}"

Your fellow executives answered:

${others}

Do you have a substantive objection to any of those positions? Only say yes if
you genuinely disagree on the decision or the reasoning. Agreeing with a
different emphasis is not a disagreement. If you object, name who and say why,
citing figures you have fetched.`,
      {
        memory: { resource: "ceo", thread: threadId },
        structuredOutput: { schema: verdictSchema },
      },
    );

    const verdict = response.object ?? {
      disagrees: false,
      with: [],
      statement: "",
    };

    return { personaId, ...verdict };
  },
});

const renderRebuttalsStep = createStep({
  id: "render-rebuttals",
  inputSchema: z.array(rebuttalEntrySchema),
  outputSchema: z.object({ transcript: z.string() }),
  execute: async ({ inputData, writer }) => {
    const markdown = renderRebuttalRound(inputData);
    await writer?.write(`\n${markdown}`);

    return { transcript: markdown };
  },
});

export const boardSessionWorkflow = createWorkflow({
  id: "boardSession",
  inputSchema: boardInputSchema,
  outputSchema: z.object({ transcript: z.string() }),
})
  // Fan the question out to all four personas.
  .map(async ({ inputData }) =>
    PERSONA_IDS.map((personaId) => ({
      personaId,
      question: inputData.question,
      threadId: inputData.threadId,
    })),
  )
  .foreach(openingStep, { concurrency: 4 })
  .then(renderOpeningsStep)
  // Fan out again, this time with everyone's openings attached.
  .map(async ({ inputData }) =>
    PERSONA_IDS.map((personaId) => ({
      personaId,
      question: inputData.question,
      threadId: inputData.threadId,
      openings: inputData.openings,
    })),
  )
  .foreach(rebuttalStep, { concurrency: 4 })
  .then(renderRebuttalsStep)
  .commit();
```

```ts
/**
 * Message history for one board thread, so the web app can rehydrate a
 * conversation the CEO left earlier. All personas share the thread, so any
 * one agent's memory handle reads the same transcript.
 */
export const boardHistoryRoute = registerApiRoute("/board/:threadId/messages", {
  method: "GET",
  createHandler: async ({ mastra }) => {
    return async (c) => {
      const threadId = c.req.param("threadId");
      const agent = mastra.getAgentById("cfo-agent");
      const memory = await agent.getMemory();

      if (!memory) {
        return c.json({ messages: [] });
      }

      const thread = await memory.getThreadById({ threadId });
      if (!thread) {
        return c.json({ messages: [] });
      }

      const { messages } = await memory.recall({ threadId, perPage: false });
      return c.json({ messages });
    };
  },
});
```

```ts
import type { UIMessage } from "ai";

const MASTRA_API_URL = process.env.MASTRA_API_URL ?? "http://localhost:4111";

export const maxDuration = 120;

/** assistant-ui sends UIMessages; the workflow wants a single question string. */
function lastUserText(messages: UIMessage[]): string {
  const lastUser = [...messages].reverse().find((message) => message.role === "user");

  return (lastUser?.parts ?? [])
    .filter((part): part is { type: "text"; text: string } => part.type === "text")
    .map((part) => part.text)
    .join("\n")
    .trim();
}

export async function POST(req: Request) {
  const { messages, threadId }: { messages: UIMessage[]; threadId?: string } =
    await req.json();

  const question = lastUserText(messages);
  if (!question) {
    return Response.json({ error: "No question to put to the board." }, { status: 400 });
  }
  if (!threadId) {
    return Response.json({ error: "Missing threadId." }, { status: 400 });
  }

  let upstream: Response;
  try {
    upstream = await fetch(`${MASTRA_API_URL}/board`, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ inputData: { question, threadId } }),
      signal: req.signal,
    });
  } catch (error) {
    const message = error instanceof Error ? error.message : String(error);
    return Response.json(
      { error: `Cannot reach the board at ${MASTRA_API_URL}: ${message}` },
      { status: 502 },
    );
  }

  if (!upstream.ok || !upstream.body) {
    const detail = await upstream.text().catch(() => upstream.statusText);
    return Response.json(
      { error: `Board returned ${upstream.status}: ${detail}` },
      { status: upstream.status },
    );
  }

  return new Response(upstream.body, {
    status: upstream.status,
    headers: {
      "Content-Type": upstream.headers.get("Content-Type") ?? "text/event-stream",
      "Cache-Control": "no-cache, no-transform",
      Connection: "keep-alive",
      "x-vercel-ai-ui-message-stream": "v1",
    },
  });
}
```

```ts
import { METRIC_NAMES, type Quarter } from "./company-data.ts";

/**
 * Deliberately minimal: no quoted fields, no embedded commas. The uploaded
 * P&L is mock data for a prototype, and a real parser is a dependency this
 * does not need.
 */
export function parseCsv(text: string): Record<string, string>[] {
  const lines = text
    .split(/\r?\n/)
    .map((line) => line.trim())
    .filter((line) => line.length > 0);

  if (lines.length < 2) {
    throw new Error("CSV must have a header row and at least one data row.");
  }

  const header = lines[0].split(",").map((cell) => cell.trim());

  return lines.slice(1).map((line, index) => {
    const cells = line.split(",").map((cell) => cell.trim());

    if (cells.length !== header.length) {
      throw new Error(
        `Row ${index + 1} has ${cells.length} columns but the header has ${header.length}.`,
      );
    }

    return Object.fromEntries(header.map((name, i) => [name, cells[i]]));
  });
}

export function quartersFromRows(rows: Record<string, string>[]): Quarter[] {
  return rows.map((row) => {
    if (!row.period) {
      throw new Error("Every row needs a period column.");
    }

    const quarter: Record<string, unknown> = {
      period: row.period,
      segments: [],
    };

    for (const metric of METRIC_NAMES) {
      const raw = row[metric];
      if (raw === undefined || raw === "") {
        throw new Error(`Row "${row.period}" is missing the ${metric} column.`);
      }

      const value = Number(raw);
      if (Number.isNaN(value)) {
        throw new Error(`Row "${row.period}" has a non-numeric ${metric}: "${raw}".`);
      }

      quarter[metric] = value;
    }

    return quarter as unknown as Quarter;
  });
}
```

```ts
import { createStorage } from "../storage.ts";
import seed from "./company-data.json" with { type: "json" };
import type { CompanyData } from "./company-data.ts";

const STORE_KEY = "company-data:current";

let cached: CompanyData | null = null;

/**
 * Uploaded figures live in the same store as board threads, so a restart
 * keeps them. The seed dataset is the fallback for a fresh checkout.
 */
export async function setCompanyData(data: CompanyData): Promise<void> {
  const storage = createStorage();
  const store = await storage.getStore("kv");
  await store?.set(STORE_KEY, JSON.stringify(data));
  cached = data;
}

export async function getCompanyData(): Promise<CompanyData> {
  if (cached) return cached;

  try {
    const storage = createStorage();
    const store = await storage.getStore("kv");
    const raw = await store?.get(STORE_KEY);

    if (typeof raw === "string") {
      cached = JSON.parse(raw) as CompanyData;
      return cached;
    }
  } catch {
    // Fall through to the seed. A missing kv store must not break grounding.
  }

  cached = seed as CompanyData;
  return cached;
}
```

## Known Risks

**Structured output in pass two.** `response.object` is assumed to be populated when `structuredOutput` is passed. Task 6 Step 4 is where this surfaces; if `object` is undefined, the fallback in `rebuttalStep` silently turns every rebuttal into agreement. Check the smoke output for a real disagreement before moving on.

**`writer` in workflow steps.** `renderOpeningsStep` and `renderRebuttalsStep` write markdown strings to the workflow writer. If `workflowRoute` does not forward plain string writes as text deltas, Task 7 Step 3 will show SSE with no text. The fallback is to return the transcript from the workflow and have the Next proxy emit it as a single AI SDK text message — less pleasant, still correct.

**Key-value storage for uploads.** Flagged inline in Task 8 Step 5, with the file-based fallback spelled out.

**Cost and latency.** Eight agent calls per question, each with tool calls. Expect 30-60 seconds and a few cents per board session. `maxDuration` in the Next route is set to 120 for this reason.

**`getToolsForExecution({})` with no options.** Verified to exist on the installed `Agent` type, but every field in its options object is optional and the empty-object call is untested here. If Task 3 Step 7 throws, assert on `Object.keys(companyDataTools)` instead and drop the per-agent tool check — the factory passes the same object to all four, so the coverage lost is small.
